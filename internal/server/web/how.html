How time is counted

An agent can work for an hour while you are making dinner. So grit never counts how long a session lasted or how long the agent ran. It counts the minutes where the timestamps show a person was steering, and it writes down the reason for every one of them.

What grit reads

Claude Code and Codex already save every session to your disk. grit reads those files in the background, so there is nothing to start or stop. Tools without local logs (Cursor, Windsurf, browser chat) report through a one-line hook that calls grit hook. Adding a new tool means adding one small collector.

The rules

Two sessions at the same momentOnceYou only have one brain. Overlap is removed before syncing.

Flags

autopilot: at least half the prompts are bare go-aheads. mostly-agent: the agent ran more than four times as long as the credited time. long-idle: under a fifth of a session over an hour was credited. Flags do not remove time on their own. They tell a reviewer where to look.

Privacy

Logged hours sync as numbers only: when each session started and stopped, how much was credited, how many prompts and tool calls. No prompt text, file names or commands leave your machine. When you submit hours for a project, grit uploads that project's prompts with API keys, tokens, emails and passwords scrubbed out, so a reviewer can check the work. Submitting is always something you do on purpose.

What it cannot prove

Someone can still script fake prompts every few minutes. That is why submitted hours come with the full evidence: a reviewer can read the prompts, see whether they build on each other, and match them to commits. Version two adds a local keyboard and mouse activity signal, which makes scripted sessions far easier to spot.
